# 谁是卧底 · 角色抽取 + 观众投票

**教学定位：COE 章 → HRBP 章的过渡环节**（COE 讲完、进入第4章 HRBP 之前的开场热身/钩子游戏）。
用“谁是卧底”引出核心议题：**少数派 HRBP 如何在 COE 群体中找出彼此、HRBP 与 COE 的区别与关系**。

- 承载课程：人力资源管理前沿（第4章 HRBP）
- 词语设定：6 人 COE（平民）+ 2 人 HRBP（卧底），对应“少数 HRBP 混在 COE 群中”

## 流程

**学生端（统一入口）**：扫码 → 填“姓名 + 学号”→ 选身份
- 🎭 **我是玩家** → 自动跳转选角色页 → 点自己抽到的座位号 → 私密显示“座位号 + 词语 + 平民/卧底”
- 👀 **我是观众** → 进投票页

## 玩家积分规则

玩家在卧底页抽到角色后，底部有“🏁 游戏结束 · 结算我的积分”按钮：

| 身份 | 胜利 | 失败 |
|---|---:|---:|
| 平民 | 15 | 10 |
| 卧底 | 20 | 10 |

- **身份自动识别**（用抽到的角色，不用手选）
- 只需选择本局结果（我们赢了 / 我们输了）
- 生成复制文本：“姓名 学号 作为平民·胜利 获得15积分 ★校验码”→ 发学习通群

## 观众投票规则

- 共 **4 轮**投票，4 个方块**一开始全部可点、自由选**（不顺序解锁）
- 每轮**只能投 1 人**（8 个座位选）
- 每人**最多投 3 轮**；点第 4 个方块提示“已投满三轮”（提前投后面轮次同样占名额，防排除法）
- 分数**全程不告知**，凭判断投
- 结算按钮 → 一次揭晓：本人总分 + 每轮投谁/对错（**只显示自己的结果**）

### 计分

| 轮次 | 投对得分 |
|---:|---:|
| 第1轮 | 10 |
| 第2轮 | 8 |
| 第3轮 | 5 |
| 第4轮 | 3 |

- 命中 **2 名卧底**（2、5 号各一次）额外 **+5**

### 结果提交

结算页 → 复制按钮 → 生成文本“姓名 学号 分数 ★六位校验码”→ 发学习通群 + **同时截图**（双保险）。

## 老师端核验

把学生发来的结果文本**逐行粘贴**到核验页 → 点核验：
- ✅ 通过 = 分数未被篡改
- ❌ 不通过 = 疑似改分
- 支持多条一起核验，自动合计有效分数

## 一码一局（玩家牌面）

玩家链接形如 `#deck=1:civ,2:spy,...`，牌局编码在 URL 里，8 台手机读同一副牌，避免各抽各的导致卧底数量出错。`civ`=平民（COE，6 人），`spy`=卧底（HRBP，2 人）。

改词：编辑 `index.html` 顶部 `CONFIG.words`（`civilian` 平民词 / `spy` 卧底词）。

## ⚠️ 事故复盘：#deck 一漏，全盘乱（2026-10-14）

> **这是本项目的头号坑。上线前、改局时、加新入口时必须重读本节。**

### 事故现象
学生从统一入口 `/vote/` 选“我是玩家”跳转后，牌面变成 **2、8 号为卧底**（随机发牌），而本局正确牌面是 **2、5 号**。属于**静默故障**——不报错、不告警，到现场玩家抽完才暴露。

### 根因
`vote/index.html` 的 `renderPlayer()` 跳转 URL 只带了 `?name=&sid=`，**漏了 `#deck=...` 牌局编码**。

而 `index.html` 的逻辑是：
```
URL 带 #deck= → 用固定牌局（正确）
URL 不带      → dealCards() 现场随机发牌（错误）
```
→ 于是所有从统一入口进来的玩家都随机抽牌，与老师控制的固定牌局脱节。

### 修复
commit `7ef6f42`：在 `renderPlayer()` 补回 deck 字符串。已 push 上线。

### 🔴 三条铁律（血泪版）
1. **`#deck=` 是本游戏唯一的“牌面真相来源”。任何跳转、入口、二维码都必须携带它。**
   - 上线前必验：打开入口页 → 点“我是玩家” → **看地址栏有没有 `#deck=`**。没有就是没修好。
2. **牌局编码目前硬编码在 4 处，必须同步改（改局时逐项打勾）：**
   - [ ] 老师端 `?host=1` 生成的 deck（学生链接里的）
   - [ ] `vote/index.html` 的 `CONFIG.spies` 数组（座位号，如 `[2,5]`）
   - [ ] `vote/index.html` `renderPlayer()` 里的 deck 字符串
   - [ ] `本局牌面.txt`
   > 漏改任何一处 = 玩家页与投票页对不上本局牌面。
3. **不要依赖“随机发牌”兜底。** 它的存在让“丢 deck”变成无声故障。**建议**：URL 无 `#deck=` 时改为**显示“本局未固定牌局，请从老师入口进入”**，而不是静默随机（待 Cressy 确认后再动，别擅自改）。
